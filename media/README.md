# مجلد الوسائط (media)

ضع أصولك هنا ثم اكتب مسارها في لوحة التحكم:

| الملف | الاستخدام | مثال المسار |
|---|---|---|
| `logo.png` | شعار يظهر فوق البث — PNG بخلفية شفافة | `media/logo.png` |
| `subject.png` / `clip.mp4` | صور/فيديوهات تعرضها فوق البث (PiP) عند الحديث عنها | `media/subject.png` |
| `break.png` | خلفية شاشة الاستراحة (اختياري) | `media/break.png` |
| `break.mp3` | موسيقى خلفية شاشة الاستراحة (اختياري) | `media/break.mp3` |

- المسارات في اللوحة تكون نسبية لمجلد المشروع أو مطلقة من الخادم.
- الخط العربي `fonts/NotoSansArabic-Bold.ttf` (رخصة OFL) يُستخدم لرسم
  نصوص شاشة الاستراحة داخل الفيديو مباشرة — لا تحذفه.
